# GenAI Agent Lab

A starter project for experimenting with agent frameworks in LangChain using OpenAI.

## Features
- Modular agent setup with tools
- MCP: Easily control model config (model, temperature)
- Tools: Calculator, mock web search
- Extendable: Add vector DBs, file readers, RAG, and more

## Run
```bash
pip install -r requirements.txt
python agent_runner.py
